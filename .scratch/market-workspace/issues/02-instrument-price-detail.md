# 02 — 標的走勢詳情

**What to build:** 讓使用者在市場工作台選取一個指數或自選股後，能在同一頁查看該標的的日 K 線與成交量，並切換少量常用期間來比較不同時間尺度；版面以桌面工作台為主，在手機上仍可基本閱讀與操作。

**Blocked by:** 01 — 市場快照與工作台總覽

**Status:** ready-for-agent

- [ ] 選取不同標的會在同一頁更新走勢，不需要離開市場工作台
- [ ] 圖表以 market snapshot 中所選標的的 `priceSeries` 顯示日 K 線與成交量
- [ ] 使用者可切換少量明確期間，切換只影響目前顯示的資料範圍
- [ ] 無價格資料時呈現清楚的空狀態，不讓圖表初始化失敗
- [ ] 圖表延續既有 lightweight-charts 能力，不新增圖表依賴
- [ ] 第一版不加入均線、RSI、MACD、畫線工具或盤中資料
- [ ] 桌面版維持可掃描的工作台資訊密度；手機版不發生文字、控制項或圖表重疊
- [ ] 不修改遊戲 `Scenario` 或既有遊戲的圖表行為，除非是兩個消費者都需要的最小相容調整
- [ ] `bun run test` 與 `bun run build` 通過
