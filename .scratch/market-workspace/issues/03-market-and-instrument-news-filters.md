# 03 — 市場與標的新聞篩選

**What to build:** 讓使用者在市場工作台閱讀全市場或目前標的的新聞，依標的、日期區間與多選類別縮小資訊範圍，並從最新消息開始閱讀原文或既有繁中摘要。這張票完成第一版市場資訊垂直切片與私有真實資料邊界。

**Blocked by:** 01 — 市場快照與工作台總覽

**Status:** ready-for-agent

- [ ] news item 支援日期時間、標題、可顯示內容、可選原文 URL、可選繁中摘要、零個或多個 symbols，以及一個或多個 categories
- [ ] 固定多選分類為總經、產業、公司、財報、政策法規、其他
- [ ] 沒有 symbols 的新聞可顯示於市場範圍；帶有目前 symbol 的新聞可顯示於標的範圍
- [ ] 使用者可切換市場新聞與目前標的新聞
- [ ] 使用者可依標的、日期區間與一個或多個類別篩選新聞
- [ ] 新聞預設最新優先，不使用遊戲的 `isKeyEvent` 作為市場資訊的排序或篩選依據
- [ ] 有原文 URL 時可開啟原始來源；有繁中摘要時顯示摘要，沒有時不呈現空白占位
- [ ] 篩選與排序是純函式，Vitest 覆蓋市場／標的 scope、日期邊界、多選類別及最新優先
- [ ] UI 不建立通用篩選引擎，也不顯示尚未有資料的 EPS、財報或其他未來模組占位
- [ ] toy snapshot 的新聞可公開再散布；本機真實新聞與產生的 market snapshot 不會被提交或打包進公開部署
- [ ] 桌面與手機版皆可操作篩選、閱讀新聞，且不發生控制項或文字重疊
- [ ] `uv run pytest`、`bun run test` 與 `bun run build` 全部通過
