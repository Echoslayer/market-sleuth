# 08 — 濃縮漲跌原因選項題型（候補 / icebox）

**What to build:** 一種新的答題機制：出題者把某次漲跌的原因濃縮成幾個選項（例如「A. 財報超預期 B. 產業利多 C. 大盤帶動」），玩家單選正確主因，而不只是從新聞列表勾「哪些是關鍵事件」。需要新的資料欄位（每關的選項與正解）、新的 UI、新的計分。

**Blocked by:** 02（延續 url/source 之後的資料契約；實際做時再確認）；與現有「勾關鍵新聞」機制並存或取代由屆時決定

**Status:** icebox

- [ ] 待現有「勾關鍵新聞 / 滑卡」機制（issue 04）玩起來、確認需要更明確的因果題型再啟動
- [ ] 若做：schema 加可選 `causeOptions` + `causeAnswer`（延續「可選欄位驅動模式」——有就出這種題、沒有就照舊），前端遇到沒有新欄位的舊關卡照舊玩
- [ ] 選項與正解的產生方式（人工 or LLM 濃縮）另行決定
- [ ] `scoreRound` 擴充計分，不破壞既有關卡

## Comments

**為何 icebox：** Q9 已決定「現在不做、不預先佔 schema 位」——沒有實作驗證的 schema 設計必然是錯的，等真要做時再一次做對。擴充性靠既有的「可選欄位驅動模式」慣例（先例：`revealCutoffDate` 有就 predictive、沒有就 detective），不需要現在寫任何程式。相關的「資料模糊性」（一個漲跌常沒有單一明確主因）是出題品質問題，靠挑因果清楚的事件解決，寫進未來出題指南，不在本 issue 範圍。
